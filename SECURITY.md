# Security Policy

## Reporting a Vulnerability

Do not report security vulnerabilities through public issues, discussions, pull
requests, or other public channels. Report them privately to:

support@banban.work

Please include, where available:

- The affected Banban AI version and deployment environment.
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue or a proof of concept.
- Relevant logs, screenshots, or configuration details with credentials,
  personal data, and other sensitive information removed.

## Handling Reports

We will review submitted reports, assess their impact, and determine an
appropriate remediation plan. We may contact you for additional information
while investigating the report.

## Coordinated Disclosure

To help protect users, please do not publicly disclose a reported vulnerability
until we have investigated it and coordinated a fix or public advisory with you.

## Supported Versions

Please report vulnerabilities regardless of the affected version. The project
will evaluate whether a security fix is available for the affected version and
may provide the fix in a supported release.
