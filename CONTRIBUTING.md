# Contributing to Banban AI

Thank you for your interest in contributing to Banban AI. Contributions of all
sizes are welcome, including bug reports, documentation improvements, tests,
and code changes.

## Before You Start

- Follow the [Code of Conduct](CODE_OF_CONDUCT.md) in all project spaces.
- Review the applicable [license terms](LICENSE) before contributing.
- Do not include credentials, personal data, customer data, or other sensitive
  information in issues, pull requests, logs, screenshots, or test fixtures.
- For a significant change, open an issue first to discuss the problem and
  proposed approach.

## Reporting Bugs

Before opening an issue, search existing issues to avoid duplicates. A useful
bug report includes:

- The Banban AI version and deployment environment.
- Clear steps to reproduce the issue.
- The expected and actual behavior.
- Relevant error messages, logs, or screenshots with sensitive information
  removed.

## Proposing Changes

Use an issue to describe a proposed feature, behavior change, or substantial
refactor before investing significant implementation effort. Explain the
problem being solved, the expected behavior, and any compatibility impact.

## Pull Requests

- Keep each pull request focused on one logical change.
- Use a clear title and describe the problem, solution, and user impact.
- Include tests for behavior changes or bug fixes where practical.
- Run the relevant build, test, and lint checks before requesting review.
- Update documentation when a change affects installation, configuration,
  operation, or public APIs.
- Do not include unrelated formatting changes, generated files, or sensitive
  information.

Maintainers may request changes before merging a pull request. Small,
independently reviewable pull requests are generally easier to review and
merge.

## Security Vulnerabilities

Do not report security vulnerabilities through public issues. Report them to
support@banban.work and include enough detail for the team to reproduce and
assess the issue.

## Contribution Terms

By submitting a contribution, you confirm that you have the right to submit it.
You agree that the contribution may be used for commercial purposes, including
cloud service operations, as permitted by the applicable project license and
agreements.

## Getting Help

For general contribution questions, contact support@banban.work.
